1. 
이진숫자: 0,1로 이루어진 숫자
프로그래밍언어: 컴퓨터가 이해할 수 있는 이진코드로 변환되는것을 목표로한 사람이 쉽게 이해할 수 있는 형태의 언어
소스코드: 프로그래밍언어로 작성한 코드
텍스트 에디터: 글자를 입력할 수 있는 모든 종류의 프로그램
통합개발환경(IDE): 텍스트 에디터와 코드 실행기 2가지 모두 포함하고있는 프로그램
개발환경: 텍스트 에디터를 포함해 컴파일러 버전과 같은 개발 플랫폼
인터프리터: 프로그래밍 소스 코드를 실행해주는 프로그램
대화형셸: 컴퓨터와 상호작용하는 공간
표현식: 어떤값을 만들어내는 코드
문장: 표현식이 하나 이상 모인것
키워드: 의미가 부여된 특별한 단어
식별자: 함수나 변수의 이름을 붙일때 사용하는 언어
변수: 값을 저장할 때 사용하는 식별자
함수: 코드의 집합
연산자: 연산에 사용되는 기호
리터럴: 입력된 값

2. 
자료형: 자료의형태
이스케이프문자: \ 기호가 붙은 특수한 문자 리터럴
인덱스: 리스트, 문자열같은 자료형에서 자료가 메모리에 저장된 순서대로 매겨진 번호
부동소수점: 소수점이있는 실수 데이터 저장하는 방식
캐스트: 어떤 자료형을 다른 자료형으로 바꾸는것

3.
조건문: 조건에 따라 코드를 실행 OR 실행X 
비교연산자: 불을 만드는 연산자
논리연산자: 비교연산자로 만들어진 불끼리 연산할 수 있는 연산자

4.
반복문: 조건문과 같이 프로그램의 진행을 바꿀때 사용하는것
이터러블: 내부에있는 요소들을 차례대로 꺼낼 수 있는 객체
비파괴적함수: 원본을 변화시키지 않는 함수
파괴적함수: 원본을 변화시키는 함수
리스트 내포: 반복문의 요소를 삽입할때, 한줄로 작성할 수 있도록 제공하는 문법
전개 연산자: 리스트 요소를 나열해주는 연산자

5. 
리턴: 함수를 실행했던 위치로 돌아가게함
매개변수: 함수를 호출할 떄 필요한 데이터를 외부로부터 받기 위해 사용하는것
키워드매개변수: 매개변수의 이름을 지정해 값을 입력하는 매개변수
재귀: 함수 내부에서 자기 자신을 호출
메모화: 재귀 호출에서 값을 중복 연산하지않기위해 새로운 값을 연산할때마다 결과에 따른 값을 저장하는것
팩토리얼: 1부터N까지의 곱연산
트리: 비선형 자료 구조
스트림: 프로그램이 외부파일, 외부네트워크 등과 통신할때 데이터가 흐르는 길
람다: 간단한 함수를 쉽게 구현할 수 있는 기능
튜플: 리스트와 다르게 한번 결정된 요소를 바꿀수없음
스택: 기본자료형이 정리된 공간
힙: 객체 자료형이 저장된 공간

6.
구문오류: 프로그램 실행 전 발생하는 오류
예외: 프로그램 실행중 발생하는 오류
예외처리: 예외가 발생하지않게 미리 예외 발생부분에 안정장치 설치하는것
예외객체: 예외가 발생했을때 예외에 관련된 정보가 저장되는 객체

 8.
 객체지향 프로그래밍: 프로그램을 개발하는 기법으로 객체를 먼저 만들고 하나씩 조립 및 연결해 전체 프로그램을 완성하는 기법-> 상속,다형성,캡슐화
 상속: 상위 객체를 기반으로 하위 객체를 생성하는 관계
 클래스: 객체의 포함할 변수와 함수를 미리 정의한것
 추상화: 프로그램에서 필요한 요소만을 사용해 객체를 정의
 객체: 여러가지 속성을 가질 수 있는 대상
 인스턴스: 클래스기반으로 만들어진 객체
 생성자: 클래스 이름과 같은 함수
 소멸자: 인스턴스가 소멸될때 호출되는 함수
 메소드: 클래스가 가지고있는 함수
 프라이빗 변수: 캡슐화를 위해 만들어진 문법
 가비지 컬렉터: 쓸모없는 데이터를 메모리에서 제거하는 프로그램
 오버라이드: 메소드 재정의
